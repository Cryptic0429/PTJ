# PhyLedger

PhyLedger 是一个面向**动作控制的交互式视频世界模型**的物理现象评测项目。目标是让视频中的每条物理判断都能追溯到预先定义的规则、原始视觉证据和明确的判据。

## 基本思路

1. 预先定义原子问题 `q`、适用前提、所需证据及通过/违反标准。
2. 控制器在同一会话中制造测试机会，并记录请求动作与实际执行动作。
3. 事件定位 Agent 找候选时间窗；程序从原始视频提取带帧 ID 和时间戳的证据。
4. 证据检查 Agent 确认对象、时间顺序和上下文是否足够。
5. 规则裁判 Agent 逐个 `q` 输出 `pass`、`violation`、`undetermined` 或 `untriggered`。
6. 程序汇总通过率、覆盖率和任务结果；人工校准定位与裁判误差。

“Multi-agent”首先表示职责和输入权限的划分。初期可用同一个 VLM 的不同调用实现多个角色，不把这些调用视为独立证据。具体模型须经小型人工校准集验证后选定。

## 当前状态

本仓库目前只有项目说明和协作约定，尚无评测实现、模型实验或实测分数。第一步是建立少量可观察规则及正常、异常、证据不足的视频校准样本，跑通逐规则取证与判断链路。

## 评分边界

当前关注可观察的物理约束、因果顺序、历史状态与后续交互，以及真实运行的条件对照；暂不估计加速度、摩擦系数、接触力或严格守恒残差。数值化的规则通过率不等于物理参数测量精度。
